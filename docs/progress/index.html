What these numbers do not mean

  • A decoded form with a translator case is not a form that executes correctly. Correctness is a picture, and no count on this page is one.
  • The per-title offline check (the 751-program world set translated, validated and built into real pipelines) is a separate measurement and needs the title's own files; it is in the project's progress page, not here.
  • The reference list is every form the hardware family defines, including ones no shader of ours contains. 100 % would still say nothing about speed or the picture.
  • Counts come from string and table scans: a case is where a form's name appears, so a helper or a length can be mistaken for support in one direction, and a form refused later in translation still counts.

Reference: Mesa's public ACO opcode table for GFX10 (RDNA1/RDNA2), provenance in tools/progress/rdna2_isa_forms.txt. The dashboard format is borrowed from the PS5 project AnyPS5, which asked the same question first.
